# Upload this project to GitHub

## Important project note

The supplied archive does not contain `gradle/wrapper/gradle-wrapper.jar`. The CI workflow uses the Gradle 8.9 installation provided by GitHub Actions, so it can still build without that JAR. Android Studio's Gradle-wrapper sync normally requires it. Generate it once from a machine with Gradle 8.9 installed by running:

```bash
gradle wrapper --gradle-version 8.9 --distribution-type bin
```

Then commit `gradle/wrapper/gradle-wrapper.jar` together with the project. Do not create an empty file with that name; it must be the real wrapper JAR generated by Gradle.

## Recommended: upload from a computer

1. Extract `CollegeCompanion-Android-Project.zip`.
2. Open the inner `CollegeCompanion` folder. Its contents include `app`, `gradle`, `.github`, `build.gradle.kts`, `settings.gradle.kts`, and `gradlew`.
3. On GitHub, create a **private** repository, for example `CollegeCompanion`.
4. Open the empty repository and choose **Add file → Upload files**.
5. Drag the *contents* of the inner `CollegeCompanion` folder into the upload area. Do not upload the outer ZIP or the outer wrapper folder.
6. Confirm `.github/workflows/android-ci.yml` is included. Hidden files may be hidden by your file manager; enable showing hidden files if necessary.
7. Commit to `main`.
8. Open the repository's **Actions** tab. Select **Android CI & APK Build** and inspect the latest run.
9. When it succeeds, open the run and download the `CollegeCompanion-Debug-APK` artifact. The release artifact is also produced by CI, using debug signing if no release keystore is configured.

GitHub's web uploader may impose a per-file size limit and may not preserve an entire directory tree when selecting files individually. If it cannot upload the folder structure, use Git from a computer or the Termux method below.

## Android phone method: Termux + Git

This method uploads the complete directory tree and hidden `.github` folder.

1. Install Termux from its official F-Droid or GitHub distribution (not an outdated Play Store build).
2. In Termux, run:

```bash
pkg update && pkg install git unzip
termux-setup-storage
```

3. Put `CollegeCompanion-Android-Project.zip` in your phone's Download folder.
4. Run (adjust the ZIP path if needed):

```bash
cd ~/storage/downloads
unzip CollegeCompanion-Android-Project.zip
cd CollegeCompanion-Android-Project/CollegeCompanion
```

5. Create an empty **private** GitHub repository in your browser. Do not initialize it with a README or license.
6. Configure Git and upload. Replace the values below with your own GitHub username and repository name:

```bash
git config --global user.name "Your Name"
git config --global user.email "YOUR_GITHUB_EMAIL"
git init -b main
git add .
git status
git commit -m "Add College Companion Android project"
git remote add origin https://github.com/YOUR_USERNAME/CollegeCompanion.git
git push -u origin main
```

7. When Git asks for a password, use a GitHub Personal Access Token with repository contents access, not your GitHub account password. Create the token in GitHub Settings → Developer settings → Personal access tokens. Keep it private and never put it in project files or commit it.
8. Check the repository's Actions tab for the build result.

## Build APK from GitHub Actions

The workflow is `.github/workflows/android-ci.yml`. It runs unit tests and builds debug and release APKs. A release APK built without your own keystore uses the debug signing key and is suitable for personal testing, not secure distribution or future production updates signed with a different key.

To install the APK, download the artifact, extract the APK from the downloaded artifact ZIP, open it on your Android phone, and allow installation from that source if Android asks.
